# ColorBrewer 顺序配色补全

九个不同的上游色系各保留一个六级版本，用于分级地图、热力图及有序面积编码。低值用浅色，高值用深色，图例保留单位与分级边界。

| 色系 | 示例用途 |
|---|---|
| BuGn | 绿地覆盖率 |
| BuPu | 问卷参与率 |
| GnBu | 河网监测强度 |
| OrRd | 风险集中度 |
| PuBu | 服务使用密度 |
| PuRd | 症状报告率 |
| RdPu | 分区调查响应率 |
| YlOrBr | 干旱程度 |
| YlOrRd | 热暴露等级 |

色系共享顺序编码逻辑。按整页色调和其他类别的颜色选用，同一度量在各页保持同一色系。小色块请加标签或轮廓。每项提供 SVG 和 JSON，两者合计计为一套。来源与授权见 NOTICE 和许可证。
