# GOV.UK 公共服务体验地图

**研究对象**　GOV.UK Service Manual 中的体验地图示例与制作流程。以下为独立研究记录。

将用户经历按阶段横向排列，再沿纵向对齐触点、情绪变化和未解决的需求。相同阶段内保留不同渠道，以便看清线上与线下交接处的问题。

| 阅读层 | 放置内容 |
|---|---|
| 阶段 | 用动词短语标出每段旅程的起点和目标 |
| 行为与触点 | 按发生顺序排用户行为，在同一列标注负责部门 |
| 证据 | 把访谈或观察记录编号挂到对应触点 |
| 改进机会 | 将相邻痛点归为一组，给出负责人和待验证问题 |

迁移到 PPT 时，按用户群拆页。如果流程相似但痛点不同，可保留同一列网格，让听众能直接对照。

[来源 · GOV.UK Creating an experience map](https://www.gov.uk/service-manual/user-research/creating-an-experience-map)
