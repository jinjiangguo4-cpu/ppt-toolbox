# USWDS 多阶段进度页

**研究对象**　USWDS Step indicator 的 Default 示例。以下为独立研究记录。

示例同时提供整段流程和当前位置。已完成、当前、待开始三种状态各自可读，当前位置的标题将观众从整体流程带入具体步骤。

| 区域 | 迁移到 PPT 时的处理 |
|---|---|
| 顶部阶段带 | 固定在章节页同一位置，每个阶段使用简短名称 |
| 当前阶段 | 用标题和形状共同标记，保证灰阶下可分辨 |
| 本页正文 | 说明当前阶段的产出、风险及下一次检查点 |
| 页脚 | 注明更新时间，避免进度与历史材料混淆 |

适用于实施计划和项目交接。若各工作流同时推进，应改用泳道表达并行关系。
